# IoT_ThucHanh_3

Thực hành buổi 3 IoT: lập trình Python với giao thức CoAP.

Bộ bài làm gồm đủ 7 chương trình cho ba bài: gửi nhận thông điệp GET/POST, mô phỏng cảm biến nhiệt độ và độ ẩm, điều khiển đèn GET/PUT và giám sát bằng CoAP Observe.

- [Hướng dẫn cài đặt và chạy từng bài](CoAP_Lab/README.md)
- [Mã nguồn bài 1](CoAP_Lab/bai1)
- [Mã nguồn bài 2](CoAP_Lab/bai2)
- [Mã nguồn bài 3](CoAP_Lab/bai3)
- [Kết quả kiểm thử thực tế qua UDP](CoAP_Lab/evidence/verification.txt)
- [Log minh chứng](CoAP_Lab/evidence)

Môi trường kiểm thử: Python 3.12.14, aiocoap 0.4.17, Windows, UDP 5683. Xem hướng dẫn để cài môi trường trên máy khác.

Thông tin họ tên, mã sinh viên và lớp/nhóm cần được điền trong [README bài làm](CoAP_Lab/README.md) trước khi nộp cho giảng viên.
